# 🔐 Smart Home Security Hub

## 📌 Project Overview

Smart Home Security Hub is a web-based cybersecurity simulation designed to demonstrate how a smart home ecosystem can be monitored, secured, and managed against potential cyber threats.
The application provides a centralized dashboard for monitoring connected smart devices, simulating cyberattacks, identifying security risks, managing security controls, and promoting cybersecurity awareness.

## 🎯 Objectives 

- Simulate a smart home environment with connected devices.
- Simulate and visualize potential cyber threats.
- Implement basic security controls.
- Monitor device security status and threat alerts.
- Promote cybersecurity awareness and safe smart home practices.

## ⚙️ Features

### 🔐 Authentication
- Demo login system.
- Session-based access control.
- Default demo credentials.

### 📊 Security Dashboard
- Centralized security monitoring dashboard.
- Overview of connected devices and security status.
- Threat monitoring and security alerts.

### 🚨 Threat Simulation & Detection
Simulates common cybersecurity threats, including:
- Port Scanning
- Brute Force Attacks
- Data Exfiltration
- Threat alerts with severity levels.

### 📁 Logging System
- Records security events and simulated attack activities.
- Stores logs in browser `localStorage`.
- Allows users to download logs as a `.txt` file.

### 📡 Device Management
- Add and remove smart home devices.
- Monitor device security status.
- Mark devices as safe or compromised.

### 🛡️ Security Controls
- Firewall enable/disable toggle.
- Intrusion Detection System (IDS) toggle.
- Device isolation control.

### 🔔 Alert System
- Visual threat notifications.
- Sound alerts for critical threats.

### 📘 User Education
- Cybersecurity guidelines.
- Security awareness modules.
- Best practices for securing smart home devices.

## 🛠️ Technologies Used

- **HTML5** – Web page structure.
- **CSS3** – Styling and responsive user interface.
- **JavaScript** – Dashboard functionality, threat simulation, and application logic.
- **LocalStorage** – Client-side data and security log storage.
